## Key Design Decisions

### US Market Hours (contextual anomaly detection)
Timestamps are in **UTC**. US markets (NYSE/NASDAQ) are open:
- Before Mar 9, 2026 (EST = UTC-5): **14:30–21:00 UTC**
- From Mar 9, 2026 (EDT = UTC-4): **13:30–20:00 UTC**

Memory spikes during these hours are **expected** and labeled as normal.
Spikes outside market hours are candidates for anomalies.

### Anomaly Types (synthetic injection)
| Type | Description |
|------|-------------|
| Point spike | +20–40% sudden increase outside market hours |
| Point drop | -15–30% sudden decrease (process crash) |
| Sustained high | +25–40% elevated for 30–90 minutes |

### Models
| Model | Type | Notes |
|-------|------|-------|
| Static Threshold | Baseline | Flag if memory > 95th pct of training data |
| Dynamic Z-score | Baseline | Flag if 24h rolling z-score > 3σ |
| Isolation Forest | Unsupervised | No labels needed |
| One-Class SVM | Unsupervised | Trained on normal points only |
| Random Forest | Supervised | Uses synthetic labels |
| Logistic Regression | Supervised | Interpretable; analyzed via statsmodels |

The threshold baselines demonstrate the traditional approach and its limitations — they cannot distinguish expected market-hours spikes from real anomalies, regardless of the threshold value chosen.
